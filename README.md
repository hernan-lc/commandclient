# Command API

A **client-side** Fabric mod that exposes a small REST API on your own machine
for sending chat messages and commands as your Minecraft player.

One repository builds the mod for several Minecraft versions: shared HTTP,
config and API code lives in `common/`, and each Minecraft version contributes
only a small adapter under `versions/`.

## Features

- **Send chat and commands over HTTP** as the local player, one message or a batch.
- **Status endpoint** reporting the API, the Minecraft version and the current player.
- **Bearer-token authentication**, off by default for a loopback-only server.
- **Loopback by default** (`127.0.0.1`); exposing the API to the network is opt-in.
- **Multi-version builds** from a single source tree, one JAR per Minecraft version.

## Install

1. Build (or download) the JAR for your Minecraft version.
2. Drop `commandapi-<mod-version>+mc<minecraft-version>.jar` into your `mods/` folder.
3. Launch the client. The API listens on `http://127.0.0.1:8080` by default.

Fabric Loader is required. Fabric API is not.

## Quick start

```bash
./gradlew buildAllVersions          # every configured Minecraft version
./gradlew :versions:1.16.1:build    # a single version
```

Artifacts land in `build/distributions/` together with `manifest.json`.

```bash
curl http://127.0.0.1:8080/api/status
curl -X POST http://127.0.0.1:8080/api/chat -d '{"text":"hello world"}'
curl -X POST http://127.0.0.1:8080/api/chat -d '{"text":"/time set day"}'
```

## API endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/status` | GET | API state, Minecraft version, current player |
| `/api/chat` | POST | Send chat message(s) as the local player |
| `/api/execute` | POST | Alias of `/api/chat`, kept for compatibility |

See [docs/API.md](docs/API.md) for request and response formats.

## Configuration

Runtime settings live in `<minecraft>/config/commandapi.json`:

```json
{
  "port": 8080,
  "host": "127.0.0.1",
  "token": "",
  "authEnabled": false
}
```

An example file is in [`config/commandapi.json`](config/commandapi.json).
Binding to anything other than loopback lets other machines send chat and
commands as you — enable authentication if you do.

## Project structure

```
common/                 shared code, no Minecraft imports
  api/                  HTTP server, request/response model, auth
  config/               runtime configuration
  minecraft/            MinecraftBridge interface (the version seam)
versions/<mc-version>/  per-version Fabric module and MinecraftBridgeImpl
templates/              fabric.mod.json expanded per version at build time
versions.json           single source of truth for supported targets
scripts/                version table generation and build verification
```
