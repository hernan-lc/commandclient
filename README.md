# Command API

A **client-side** Fabric mod that exposes a small REST API on your own machine
for sending chat messages and commands as your Minecraft player.

One repository builds the mod for every supported Minecraft version, from 1.16.x
through the current 26.x releases: shared HTTP, config and API code lives in
`common/`, each Minecraft API generation gets one adapter under `adapters/`, and
`versions/` holds a four-line module per target.

> ⚠️ This API acts as **you**. Anyone who can reach its port can chat and run
> commands with your account. It listens on `127.0.0.1` only, unless you change
> that. See [docs/SECURITY.md](docs/SECURITY.md).

## Features

- **Send chat and commands over HTTP** as the local player, one message or a batch.
- **Status endpoint** reporting the API, the Minecraft version and the current player.
- **Bearer-token authentication**, off by default for a loopback-only server.
- **Loopback by default**; exposing the API to the network is opt-in and warned about.
- **Multi-version builds** from one source tree, one JAR per Minecraft version.
- **No Fabric API required** — only Fabric Loader.

### Support policy

| Tier | Meaning |
|---|---|
| **A** | Latest stable Minecraft. Supported first after a Minecraft update. |
| **B** | Current/recent ecosystem versions that mods are actively built for. |
| **C** | Historical modding anchors with lasting community use. |
| **D** | Best effort. Kept while it costs nothing; no guarantee for arbitrary patches. |

New Minecraft releases are added as Tier A as soon as Fabric Loom supports them.
Adding a version is a configuration change, so keeping up is cheap — see
[docs/ADDING_VERSION.md](docs/ADDING_VERSION.md).

## Install

1. Install **Fabric Loader** for your Minecraft version. Fabric API is *not* needed.
2. Download the JAR matching your Minecraft version:
   `commandapi-<mod-version>+mc<minecraft-version>.jar`.
3. Drop it into your `mods/` folder.
4. Launch the client. The log shows `[CommandAPI] Listening on http://127.0.0.1:8080`.

Java requirements follow Minecraft's own: Java 8 for 1.16.x, 17 for 1.18–1.20.4,
21 for 1.20.6–1.21.x, 25 for 26.x. If Minecraft runs, the mod runs.

## Quick start

```bash
curl http://127.0.0.1:8080/api/status
curl -X POST http://127.0.0.1:8080/api/chat -d '{"text":"hello world"}'
curl -X POST http://127.0.0.1:8080/api/chat -d '{"text":"/time set day"}'
curl -X POST http://127.0.0.1:8080/api/chat -d '{"messages":["one","two"]}'
```

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/status` | GET | API state, Minecraft version, current player |
| `/api/chat` | POST | Send chat message(s) as the local player |
| `/api/execute` | POST | Alias of `/api/chat`, kept for compatibility |

Full request/response formats, limits and status codes: [docs/API.md](docs/API.md).

## Configuration

Runtime settings live in `<minecraft>/config/commandapi.json`:

```json
{
  "port": 8080,
  "host": "127.0.0.1",
  "token": "",
  "authEnabled": false
}
```

An example is in [`config/commandapi.json`](config/commandapi.json). Binding to
anything other than loopback lets other machines send chat and commands as you —
enable authentication if you do.

## Build

```bash
./gradlew buildAllVersions          # every configured Minecraft version
./gradlew :versions:26.2:build      # a single version
./gradlew :common:test              # shared unit tests
```

Artifacts land in `build/distributions/` with a `manifest.json`. Requires JDK 21
(JDK 25 for 26.x targets, downloaded automatically if missing) and Python 3.
Details: [docs/BUILD.md](docs/BUILD.md).

## Troubleshooting

**The API does not respond.** Check the log for
`[CommandAPI] Listening on ...`. If the port was busy the log says so and the
server did not start — change `port` in `config/commandapi.json`.

**`503` on every request.** You are not in a world. Messages can only be sent as
a player; join a world or server first.

**`401 Unauthorized`.** `authEnabled` is true and the `Authorization: Bearer
<token>` header is missing or wrong.

**`404`.** Only `/api/status`, `/api/chat` and `/api/execute` exist.

**Commands are not running.** Send them with the leading slash (`/time set day`).
Without it the text goes to chat as an ordinary message.

**The mod does not appear in the mod list.** Check that the JAR's Minecraft
version matches the game exactly — `commandapi-…+mc1.21.11.jar` will not load on
1.21.8.

**Another machine cannot reach it.** That is the default. Set `host` and turn on
authentication — read [docs/SECURITY.md](docs/SECURITY.md) first.
